# Changelog

All notable changes to TreenAH will be documented in this file.

## [1.1.2] - 2026-05-22

### Added

- Public README with installation, quick start, slash command, troubleshooting, development, packaging, and donation guidance.
- MIT license for public reuse and contribution clarity.
- Local release packaging script for building `dist/TreenAH-v1.1.2.zip`.
- Git ignore rules for generated release artifacts and local temporary files.

### Current addon capabilities

- Auction House price history from passive browsing, item scans, tracked list scans, fast full scans, and slow full scans.
- Tooltip pricing, Auction House browse price column, tracked item lists, and recorded data browser.
- `/pc` price checks for local output, whispers, Battle.net friends, party, raid, guild, and say chat.
- Optional auto-replies to price-check requests with cooldowns, channel controls, and automatic Requests list tracking.
- In-game quick start, slash command help, debug toggles, outlier threshold settings, recent average window settings, and group/guild version checks.

### Notes

- This changelog starts from the current public source state. Earlier private/local iteration history was not reconstructed.
